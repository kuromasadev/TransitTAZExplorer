# TransitTAZExplorer
 Traffic Analysis Zone Explorer for Transit Services

## Commuter Service Area Explorer

The rider-facing website follows sector → freeway corridor → origin neighborhood → nearest commuter facility → transit destinations.

- [Open the portable HTML](./output/commuter-explorer/index.html)
- [Download the copy-ready folder as ZIP](./output/commuter-explorer.zip)
- [Usage, data methods, maintenance and SharePoint notes](./explorer/README.md)

All runtime code, styles, data and maps are embedded in the HTML. No installation or server is needed. Proximity is straight-line for now; driving catchments can be added later. The user confirmed direct file opening and the five-step flow on October 12, 2026. Browser tests over local HTTP, isolated sandbox tests, and coverage checks have passed. Actual SharePoint tenant rendering has not been tested.
